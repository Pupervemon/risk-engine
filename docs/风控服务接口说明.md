# Risk Service 接口总览

版本: `draft-2026-04-14`

状态: `current`

本文档用于简要展示 `risk-server` 当前对外暴露的接口，包含 HTTP 接口和 gRPC 接口。
如果文档与代码不一致，以当前代码、生成后的 Swagger 文档和 `risk-proto` 中的 proto 定义为准。

## 1. 接口范围

- HTTP 服务入口: `cmd/risk-server`
- HTTP 路由实现: `internal/risk/adapter/inbound/http`
- gRPC 服务实现: `internal/risk/adapter/inbound/grpc/risk_control_service.go`
- Swagger 导出目录: `docs/swagger/risk`

## 2. HTTP 接口

说明:

- BasePath: `/`
- 返回格式: `application/json`
- 管理接口需要认证头:
  `X-User-Id`: 网关解析 token 后注入的当前用户 ID
  `X-User-Roles`: 网关解析 token 后注入的当前用户角色列表，支持逗号分隔或 JSON 数组；必须包含 `2`(teacher) 或 `3`(admin)

### 2.1 健康检查与服务信息

| 方法 | 路径 | 说明 | 主要响应 |
| --- | --- | --- | --- |
| GET | `/health` | 综合健康检查，包含依赖状态 | `200` / `503` |
| GET | `/info` | 服务元信息，包括服务名、版本、协议、端口和已暴露端点 | `200` |

### 2.2 风控管理接口

| 方法 | 路径 | 说明 | 主要参数 | 主要响应 |
| --- | --- | --- | --- | --- |
| GET | `/api/v1/admin/risk-ips` | 查询风险 IP 列表，支持分页和按 IP 精确过滤 | `limit`, `offset`, `q` | `200`, `400`, `401`, `403`, `500` |
| GET | `/api/v1/admin/risk-ips/{ip}` | 查询单个风险 IP 的聚合详情 | 路径参数 `ip` | `200`, `400`, `401`, `403`, `404`, `500` |
| GET | `/api/v1/admin/risk-ips/{ip}/events` | 查询单个风险 IP 的事件历史 | 路径参数 `ip`; 查询参数 `limit`, `offset` | `200`, `400`, `401`, `403`, `404`, `500` |

### 2.3 常见 HTTP 返回结构

- 健康检查:
  `status`, `components`, `timestamp`
- 错误返回:
  `error`
- 风险 IP 列表:
  `items`, `offset`, `limit`, `total`, `has_more`
- 风险 IP 详情:
  `ip`, `severity`, `flags`, `blacklisted`, `event_count` 等
- 风险事件列表:
  `ip`, `items`, `offset`, `limit`, `total`, `has_more`

## 3. gRPC 接口

说明:

- gRPC 服务名: `RiskControlService`
- 注册位置: `pb.RegisterRiskControlServiceServer(grpcServer, riskComponents.GRPCService)`
- proto 包路径: `github.com/Pupervemon/risk-proto/gen/go/risk/v1`

| 方法 | 请求类型 | 响应类型 | 说明 |
| --- | --- | --- | --- |
| `Check` | `CheckRequest` | `CheckResponse` | 综合风控检测，当前覆盖黑名单、IP 频控、登录失败次数保护 |
| `ReportEvent` | `ReportEventRequest` | `ReportEventResponse` | 事件上报，当前主要用于登录成功/失败上报和防暴力破解计数 |
| `AddBlacklist` | `AddBlacklistRequest` | `AddBlacklistResponse` | 添加黑名单，支持按 IP 或用户 ID 写入 |
| `OnlineSelfTest` | `OnlineSelfTestRequest` | `OnlineSelfTestResponse` | 在线自测类请求的用户维度限流 |
| `JudgeSubmission` | `JudgeSubmissionRequest` | `JudgeSubmissionResponse` | 判题提交类请求的用户维度限流 |

### 3.1 gRPC 请求重点字段

| 方法 | 关键字段 |
| --- | --- |
| `Check` | `req_id`, `scene`, `ip`, `user_id`, `phone_number`, `device_id`, `timestamp` |
| `ReportEvent` | `req_id`, `scene`, `ip`, `user_id`, `is_success`, `extra_info` |
| `AddBlacklist` | `type`, `value`, `reason`, `expire_at` |
| `OnlineSelfTest` | `req_id`, `user_id`, `payload`, `timestamp` |
| `JudgeSubmission` | `req_id`, `user_id`, `answer`, `timestamp` |

### 3.2 gRPC 当前行为摘要

- `Check`
  命中黑名单时返回拒绝；IP 超频时返回拒绝；登录场景下失败次数达到阈值时返回二次验证；其他情况返回通过。
- `ReportEvent`
  当前只支持 `scene=LOGIN`；登录成功会清除失败计数，登录失败会累加失败计数。
- `AddBlacklist`
  支持写入 `ip` 或 `uid` 维度的 Redis 黑名单键，并记录风险洞察事件。
- `OnlineSelfTest`
  要求 `user_id` 非空；超过用户维度频控阈值时返回限流错误。
- `JudgeSubmission`
  要求 `user_id` 非空；超过用户维度频控阈值时返回限流错误。
