# 风控与验证码服务接口文档

版本：`2026-06-02`

## 通用约定

- HTTP 返回格式：`application/json`
- 时间字符串：RFC3339
- 管理接口鉴权头：
  - `X-User-Id` 或 `user_id`：网关注入的用户 ID
  - `X-User-Roles` 或 `user_roles`：角色列表，支持逗号分隔或 JSON 数组，必须包含 `3`
- 通用错误结构：

```json
{
  "error": "ERROR_CODE",
  "reason": "optional detail"
}
```

## 验证码 HTTP 接口

### GET `/api/v1/captcha`

生成滑块验证码。

响应 `200`：

```json
{
  "captchaId": "captcha id",
  "masterImage": "base64 image",
  "tileImage": "base64 image",
  "targetY": 42,
  "expiresIn": 300,
  "requireMouseTrack": true
}
```

错误：

| 状态码 | error |
| --- | --- |
| `500` | `CAPTCHA_GENERATE_FAILED` |

### POST `/api/v1/captcha/verify`

校验滑块位置和轨迹，成功后签发短期 token。

请求：

```json
{
  "captchaId": "captcha id",
  "pointX": 120,
  "pointY": 42,
  "mouseTrack": [
    {"x": 1, "y": 40, "t": 1710000000000}
  ]
}
```

响应 `200`：

```json
{
  "token": "captcha token",
  "expiresIn": 300
}
```

错误：

| 状态码 | error | 说明 |
| --- | --- | --- |
| `400` | `INVALID_JSON` | 请求体不是合法 JSON |
| `400` | `CAPTCHA_INVALID` | 坐标、轨迹或验证码已失效 |
| `500` | `CAPTCHA_VERIFY_FAILED` | 服务端校验异常 |
| `500` | `TOKEN_ISSUE_FAILED` | token 签发失败 |

### POST `/api/v1/admin/image-source/check`

使用当前 Redis 图片源配置拉取 1 张图片进行可用性测试，不刷新图片池。

响应 `200`：

```json
{
  "config": {
    "version": 2,
    "url": "https://example.com/image-api",
    "apiKeyConfigured": true,
    "timeoutSeconds": 5,
    "rateLimitPerMinute": 60,

    "updatedAt": "2026-06-02T11:00:00+08:00"
  },
  "validatedAt": "2026-06-02T11:05:00+08:00"
}
```

错误：

| 状态码 | error |
| --- | --- |
| `400` | `IMAGE_SOURCE_CHECK_FAILED` |
| `401` | `ADMIN_UNAUTHORIZED` |
| `403` | `ADMIN_FORBIDDEN` |
| `409` | `IMAGE_POOL_DISABLED` |
| `409` | `IMAGE_POOL_REFRESH_IN_PROGRESS` |

### PUT `/api/v1/admin/image-source`

更新 Redis 中的运行时图片源配置。接口会先校验候选配置能否拉到图片；默认不刷新图片池，只有 `triggerRefresh=true` 时才立即刷新。

请求：

```json
{
  "url": "https://example.com/image-api",
  "apiKey": "secret",
  "timeoutSeconds": 5,
  "rateLimitPerMinute": 60,
  "retryCount": 1,
  "triggerRefresh": false
}
```

所有字段均可选；未传字段沿用当前 Redis 配置。

响应 `200`：同 `GET /api/v1/admin/image-source`。

错误：

| 状态码 | error |
| --- | --- |
| `400` | `INVALID_JSON` |
| `400` | `IMAGE_SOURCE_UPDATE_REJECTED` |
| `401` | `ADMIN_UNAUTHORIZED` |
| `403` | `ADMIN_FORBIDDEN` |
| `409` | `IMAGE_POOL_DISABLED` |
| `409` | `IMAGE_POOL_REFRESH_IN_PROGRESS` |
| `500` | `IMAGE_SOURCE_PERSIST_FAILED` |
| `502` | `IMAGE_SOURCE_REFRESH_FAILED` |

### POST `/api/v1/admin/image-source/refresh`

使用当前 Redis 图片源配置刷新图片池。刷新成功后切换 active generation；刷新失败时旧图片池继续生效。

响应 `200`：同 `GET /api/v1/admin/image-source`。

错误：

| 状态码 | error |
| --- | --- |
| `401` | `ADMIN_UNAUTHORIZED` |
| `403` | `ADMIN_FORBIDDEN` |
| `409` | `IMAGE_POOL_DISABLED` |
| `502` | `IMAGE_POOL_REFRESH_FAILED` |

## gRPC 接口摘要

gRPC 具体字段以 `risk-proto` 为准。

### `captcha.v1.CaptchaTokenService`

| RPC | 请求 | 响应 | 说明 |
| --- | --- | --- | --- |
| `VerifyToken` | `VerifyTokenRequest{token}` | `VerifyTokenResponse{valid, reason, expires_at}` | 校验验证码服务签发的短期 token |

空 token 返回 `valid=false, reason=TOKEN_EMPTY`；校验异常返回 `valid=false, reason=TOKEN_VERIFY_FAILED`。

### `risk.v1.RiskControlService`

| RPC | 说明 |
| --- | --- |
| `Check` | 综合风控检测，返回 `ACTION_PASS`、`ACTION_REJECT` 或 `ACTION_VERIFY` |
| `ReportEvent` | 上报业务事件，例如登录成功/失败 |
| `AddBlacklist` | 添加黑名单项 |
| `OnlineSelfTest` | 在线自测限流判断 |
| `JudgeSubmission` | 判题提交限流判断 |

关键枚举：

| 枚举 | 值 |
| --- | --- |
| `Scene` | `SCENE_UNKNOWN`, `SCENE_LOGIN`, `SCENE_REGISTER`, `SCENE_PAYMENT` |
| `Action` | `ACTION_PASS`, `ACTION_REJECT`, `ACTION_VERIFY` |
| `BlacklistType` | `TYPE_IP`, `TYPE_USER_ID`, `TYPE_DEVICE` |
